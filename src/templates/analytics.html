Methodology Notes:
  • Chronological Holdout Split: Train set spans 1997 through 2015 (261,337 records). Test set spans 2016 through 2020 (65,335 records) to strictly test future temporal generalization.
  • Leakage Prevention: Yield is excluded from the feature inputs of the Production model, and Production is excluded from the Yield model.

Predictive Pipeline Architecture

Pre-processing and feature transformation specifications.

Categorical Preprocessing

  • OrdinalEncoder: Transforms State, District, Crop, Season
  • Out-of-Vocabulary: Unknown categories mapped safely without throwing errors
  • Feature Alignment: Exact column preservation between training and inference

Numerical Scaling

  • StandardScaler: Standardizes Cultivated Area and Agricultural Year
  • Zero/Negative Filtering: Area must strictly exceed 0.0 ha
  • Outlier Trimming: Extreme yield entries (> 99.9th percentile) filtered

Serialization & Deployment

  • Joblib Persistence: Serialized to models/production_model.joblib and yield_model.joblib
  • Sub-Millisecond Inference: Models pre-loaded at server boot
  • Zero Retraining Delay: Instantaneous responses for web clients
